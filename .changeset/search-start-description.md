Add the `extraDescription` and `movesFocusOnSelect` props to autosuggest, and the `searchStartsOnSelect` prop to the panel. The panel adds the description to a field only when the other field is set, and the origin field no longer claims that focus moves to the destination when the destination is set or on mobile.
